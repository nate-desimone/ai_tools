# Lard Catalog

These are common sources of lard and their fixes. `prose_audit.py` flags many of them automatically; this catalog is broader, and it covers judgment calls the script can't make. Always check the replacement against the context. Some entries carry real meaning in specific situations.

## 3. "Is" + Adjective or Noun + Preposition → Verb

| Lard | Replace with |
|------|--------------|
| is dependent on | depends on |
| is indicative of | indicates |
| is reflective of / is a reflection of | reflects |
| is supportive of | supports |
| is in need of | needs |
| is aware of / has knowledge of | knows |
| is in agreement with | agrees with |
| is in compliance with | complies with |
| is applicable to | applies to |
| is responsible for + -ing | (actor + verb) |
| was in attendance | attended |
| is of the opinion that | thinks, believes |
| is in possession of | has |

**Agent nouns** (-er, -or, -ant) hide verbs too:

| Lard | Replace with |
|------|--------------|
| are (active) participants in | participate in |
| is a user of / heavy user of | uses / uses heavily |
| is a contributor to | contributes to |
| is a provider of | provides |
| are supporters of / is a believer in | support / believes in |

Role nouns that state membership or title stay: "She is a member of the board", "He is the owner of the module".

## 4. Redundant Pairs (Doublets)

Pick one word: each and every, first and foremost, any and all, full and complete, true and accurate, various and sundry, hopes and desires, null and void, basic and fundamental, ways and means, aid and abet, plain and simple, over and done with.

**Synonym stacks** do the same thing without "and": "important, significant changes", "clear, concise prose", "quick, rapid response". Keep the stronger word, or the more specific one.

The category noun adds nothing to the word it categorizes.

| Lard | Replace with |
|------|--------------|
| in a timely manner / fashion | promptly |
| in a(n) _X_ manner / fashion | _X_-ly (e.g., "in an efficient manner" → "efficiently") |
| on a daily / weekly / regular basis | daily / weekly / regularly |
| of a confidential nature | confidential |
| large in size / red in color / square in shape | large / red / square |
| at an early stage / time | early |
| in the area / field / realm / domain of | in |
| the process of + -ing | (cut "the process of") |
| the issue / topic / subject of X | X |

## 7. Slow Windups and Throat-Clearing

Usually cut these entirely.

- It is important / interesting / worth noting that ...
- It should be noted / mentioned / emphasized that ...
- It goes without saying that ... / Needless to say, ...
- The fact of the matter is that ...
- The point I want / wish to make is that ...
- It is widely / well / generally known / accepted / understood that ... This is a claim about who agrees. Cut it, or say who.
- What this means is that ...
- The reason (why) ... is because ... → because ...
- As previously mentioned / stated / discussed, ...
- The purpose of this document / section is to ...
- In this section, we will discuss ...
- I would like to take this opportunity to ...
- In today's fast-paced / rapidly evolving / ever-changing world / landscape, ...
- When it comes to X, ... → For X, ...
- At the end of the day, ...
- For all intents and purposes, ...
- Please do not hesitate to ... → Please ...
- First of all → First. Last but not least → Finally.

## 8. Empty Intensifiers and Reflexive Hedges

Cut these unless they carry real meaning. If a claim needs "very", use a stronger, more specific word or a number.

- **Intensifiers:** very, really, quite, rather (but keep "rather than"), extremely, truly, totally, absolutely, definitely, highly, incredibly, super.
- **Inflating adjectives:** ample, considerable, substantial, significant (when not statistical), major, key, critical (when everything is critical). Replace them with the number or cut them.
- **Filler adverbs:** basically, essentially, actually, literally, simply, obviously, of course, clearly (as a claim of obviousness; "explain clearly" is fine).
- **Reflexive hedges:** kind of, sort of, somewhat, fairly, a bit, I think, I believe, I feel, in my opinion, it seems that, arguably. Keep a hedge when you're contrasting opinion with fact or when the uncertainty is real.

**Self-evaluations and status reports:** Hedges like "I think I helped" undersell the work. Use concrete verbs and outcomes instead: "I designed X, which cut build time 40%."

## 9. Double Negatives and Needless Negatives

Readers process positive statements faster than negative ones. Two negatives make them do arithmetic.

### Double negatives (litotes) → positive

| Before | After |
|--------|-------|
| not uncommon | common, frequent |
| not unlike | like, similar to |
| not insignificant | significant (or give the number) |
| not unreasonable | reasonable |
| not impossible | possible |
| not irrelevant | relevant |
| not dissimilar | similar |
| not infrequently | often |
| not without merit | has merit |
| cannot X without Y | must Y to X / X requires Y |
| not ... unless | only if |
| no one ... not | everyone |
| failed to not | (rewrite) |

### Single negatives that hide a positive verb

| Before | After |
|--------|-------|
| did not remember | forgot |
| did not pay attention to | ignored |
| does not have | lacks |
| does not include | omits, excludes |
| is not the same as | differs from |
| not many | few |
| not often | rarely |
| did not accept | rejected |
| not able to | unable to, cannot |
| not ... until | only when / only after |
| not honest | dishonest |

**Exception:** Keep a negative when the negation is the point ("The driver does **not** support hot-plug"). Readers often skim past "un-" and "in-" prefixes, so an explicit "not" is safer for critical warnings.

## 10. Noun Stacks

Three or more nouns in a row force readers to parse the phrase backward ("system performance monitoring tool configuration").

Unpack the stack:

1. Find the head noun (the last one).
2. Find the action hidden in the stack.
3. Rebuild the phrase with a verb and one or two prepositions.

| Before | After |
|--------|-------|
| firmware update delivery mechanism | the way we deliver firmware updates |
| customer issue resolution time reduction | reducing the time to resolve customer issues |
| test coverage improvement initiative | an effort to improve test coverage |

Established compound terms ("memory controller", "boot loader", "pull request") are not stacks. Leave them alone.

## 11. Jargon and Buzzwords

Plain words read faster and sound more confident. Keep a term of art only if the audience uses it daily.

| Buzzword | Plain word |
|----------|------------|
| leverage | use |
| utilize | use |
| facilitate | help, enable, run (for meetings) |
| synergy / synergize | (say what actually combines) |
| align / drive alignment | agree |
| going forward / moving forward | from now on (or cut) |
| circle back / touch base | follow up, talk |
| bandwidth (meaning time) | time |
| impactful | effective, significant (or show the impact) |
| best-in-class / world-class / cutting-edge / robust | (cut, or give the evidence) |
| actionable insights | findings, recommendations |
| value-add | benefit |
| deep dive | analysis, review |
| learnings | lessons |
| ideate | brainstorm, think of |
| operationalize | put into practice, run |

## 12. Document-Level Redundancy

- **Restating the heading:** "## Testing" followed by "This section describes testing." Cut the sentence.
- **Echo summaries:** an introduction that previews, a body that says it, and a conclusion that repeats it. Keep one preview only if the document is long.
- **Repeated context:** background re-explained in each section. Explain it once and refer back to it.
- **Parallel bullets that overlap:** "Improved reliability" and "Reduced failures". Merge them and give the number.
- **Tables plus prose saying the same thing:** Keep the table and use the prose for the takeaway.
